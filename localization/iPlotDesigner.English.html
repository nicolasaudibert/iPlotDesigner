iPlotDesigner - Interactive plot design and R code generation

Nicolas Audibert

Université Sorbonne Nouvelle, département ILPGA

Laboratoire de Phonétique et Phonologie (CNRS & Sorbonne Nouvelle)

Load a data file, select a quantitative dependent variable and one or more independent variables to display and export various types of plots comparing the distribution of the dependent variable across modalities of the independent variables.

You can interactively adjust the main graphical parameters (factor order, size, color and transparency of different elements, font, background transparency or color) and navigate between different types of representations by changing tabs.

Available visualizations:

  • Bar chart: Shows means with error bars (standard error or standard deviation)
  • Box plot: Displays quartiles and outliers
  • Violin plot: Combines density estimation with box plot
  • Histogram: Shows frequency distribution with overlapping or stacked bars
  • Density plot: Displays smoothed distribution curves
  • Ridge plot: Shows distributions offset vertically for better comparison

For each displayed figure, you can optionally display and download the R script code to load the dataset and generate the same figure offline, with explanatory comments included in the code.

Data protection note: Uploaded data is processed locally in your browser session. Data is not retained after the application is closed or your session expires. If you are processing sensitive data, consider using the local version of the application downloaded from GitHub.
